# Mission: Build and maintain Cornix LP ZMK firmware

## Why

I want to understand enough ZMK to safely customize, build, flash, recover, and publish firmware for my Cornix LP split keyboard.

## Success looks like

- Explain what the keymap, board files, build.yaml, and UF2 files each do.
- Change a key or behavior in config/cornix.keymap and build both halves.
- Recover a split keyboard when the halves lose their pairing.
- Keep personal work in a GitHub fork without accidentally publishing local dependencies.

## Constraints

- Beginner-friendly, hands-on teaching on macOS.
- Cornix LP controllers report as E73/nRF52840.
- Network commands should use the local proxy at port 7890 when needed.

## Out of scope

- Designing new keyboard hardware or replacing the original PCB firmware right now.
