# Cornix ZMK Resources

## Knowledge

- [Installing ZMK](https://zmk.dev/docs/user-setup) — official setup and build/flash workflow. Use when setting up a new machine or CI build.
- [Split Keyboards](https://zmk.dev/docs/features/split-keyboards) — central/peripheral roles and how key events move between halves. Use when diagnosing one half not working.

- [Fork a repository](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/fork-a-repo?tool=cli) — official GitHub CLI fork workflow.
- [Working with forks](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks) — explains upstream and personal remotes.
