Quick reference

Cornix ZMK cheat sheet

The few files and commands that matter most when customizing this keyboard.

config/cornix.keymap

Which physical positions produce which keys and behaviors.

config/cornix.conf

Feature switches such as NKRO and radio power.

build.yaml

Which left/right firmware images to build.

firmware/*.uf2

Compiled images copied to the nRF52840 bootloader drive.

Cornix roles

  • Left: central half; owns the keymap state, connects to the Mac, and is the ZMK Studio endpoint.
  • Right: peripheral half; sends its key positions to the left over split BLE.
  • The right half normally does not appear as a separate keyboard in ZMK Studio.

Normal build

export ZEPHYR_TOOLCHAIN_VARIANT=gnuarmemb
export GNUARMEMB_TOOLCHAIN_PATH=/opt/homebrew
.venv/bin/west build -s zmk/app -d build/cornix-left   -b cornix_left//zmk -- -DSHIELD=cornix_indicator   -DZMK_CONFIG="$PWD/config" -DZMK_EXTRA_MODULES="$PWD"

# In this repo, the checked-in UF2 files are already built:
# firmware/cornix_left.uf2
# firmware/cornix_right.uf2

Split recovery

Flash a settings-reset image to both halves, then flash the normal image to both halves. Reset images erase pairing and ZMK Studio settings, so forget the old Mac Bluetooth entry and pair again.

right  → firmware/cornix_right_settings_reset.uf2
left   → firmware/cornix_left_settings_reset.uf2
right  → firmware/cornix_right.uf2
left   → firmware/cornix_left.uf2

GitHub fork workflow

git status
git remote -v
git log --oneline -5
git add -- config/cornix.keymap
git commit -m "describe the change"
git push fork main

origin points to the original repository in this checkout; fork points to happychau0v0/cornix-zmk-config. Never stage the untracked ZMK dependency trees just because they appear in git status.
